# Pandas: данные студентов

> Практика Pandas: чтение CSV, очистка пропусков, сортировка, группировка и визуализация данных студентов.

**Стек:** Python · Pandas · Matplotlib · CSV

## Темы

Чтение `students.csv`, первичный осмотр, сортировка, заполнение пропусков, группировка и графики.

## Запуск

```bash
python -m pip install pandas matplotlib
python "Задание 1.py"
```

Запускайте из корня репозитория, где лежит `students.csv`. Для работы по ячейкам есть `Untitled4.ipynb`.
